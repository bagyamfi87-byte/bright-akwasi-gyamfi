## Study design

The study uses a longitudinal, structured comparative documentary design. Malaysia is the focal case for 2016-2026, with China, Japan, South Korea, India and Singapore as institutional comparators. The institutional status cutoff used in the manuscript is **24 September 2026**.

The repository contains coded documentary evidence rather than confidential microdata. The analysis is based on public official policy, regulatory, reporting and technical documents. No human-participant data are included.

## Repository files

- `02_caiif_codebook.csv` - Carbon Accounting Integrity and Interoperability Framework (CAIIF) analytical codebook.
- `03_malaysia_official_corpus.csv` - core Malaysian official carbon-accounting corpus, 2016-2026.
- `04_current_status_profile.csv` - CAIIF current-status profile across the six jurisdictions.
- `08_caig_diagnostic_malaysia.csv` - Carbon Accounting Integration Gap (CAIG) diagnostic for Malaysia.
- `09_appendix_caiif_evidence_matrix.csv` - source-level evidence matrix used for current-status coding.
- `DATA_AVAILABILITY.txt` - journal-ready data availability statement.
- `CITATION.cff` - citation metadata.
- `LICENSE.md` - licence information for the derived coding dataset.

## Coding conventions

For the current-status profile, `O` denotes explicit/operational evidence. `P` denotes a substantive mechanism that is proposed, phased, provisional, fragmented or developing. `N` denotes no current dedicated evidence identified within the defined search boundary. Appendix-level coding preserves descriptive P sub-statuses where applicable. These codes are documentary status categories, not country rankings or measures of climate-policy performance.

## Source-data note

The repository does not redistribute the full underlying government, regulatory or standards documents. Those documents remain available from their respective issuing institutions and are subject to their own terms of use. The dataset records the study's coding, evidence locators and source metadata needed to reproduce the documentary classifications. Source URLs are provided in the manuscript reference list.

## Data availability statement

The documentary coding dataset and reproducibility files supporting this study are openly available in this GitHub repository. The underlying official policy, regulatory and technical documents are publicly available from the issuing institutions; source links are provided in the manuscript. No confidential or human-participant data were used.
